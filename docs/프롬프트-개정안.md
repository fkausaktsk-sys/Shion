## 이 프로젝트의 목표

**기존 내용은 살리고, 너무 오래된 홈페이지를 세련된 최신 느낌으로 바꾸는 것.** 기능을 늘리는 프로젝트가 아닙니다.

- "심플"은 **작업 과정**을 어렵게 하지 않는다는 뜻입니다. 디자인과 애니메이션은 심플하게 줄이지 않고, 요즘 느낌으로 공들여 만듭니다.
- 페이지 수와 기능은 최소로 둡니다. 게시판, 관리자 화면, 회원, 견적 접수 폼은 만들지 않습니다.
- 이미지는 다른 AI로 따로 다듬습니다. 그래서 이 프로젝트는 원본 이미지를 정리해 넘기고, 다듬은 이미지를 받아 끼우기 쉬운 구조만 만듭니다.
- 원본 프롬프트의 좋은 점(단계마다 멈춤, 연락처는 site.json 한 곳, 시안 먼저 보고 선택)은 그대로 둡니다.

## 0단계 프롬프트: 백업과 이미지 정리

```
shion.co.kr(주식회사 시온건설) 리뉴얼 0단계: 기존 사이트의 글과 이미지를 로컬에 모아줘.
현재 사이트는 그누보드(PHP) 게시판 기반이고, 우리 고객사의 사이트이며 이 작업은 고객이 승인한 작업이다.
글을 도구로 하나씩 열지 말고 로컬에서 실행하는 Node 스크립트로 처리한다. 스크립트는 scripts/, 결과는 backup/ 에 둔다.

[모을 것]
- 기업소개(인사말, 회사연혁, 회사등록증, 기술경력증, 사훈, 보유장비, 오시는길), 주요사업: 글 텍스트와 이미지.
- 시공사진·시공동영상·시공사례: 각 글의 제목, 작성일, 본문 텍스트, 이미지. 동영상은 유튜브 주소인지 직접 업로드 파일인지 기록한다.
- 공지사항과 견적문의는 모으지 않는다.
- 메뉴의 시공사진(yp_album01)과 메인 최신글(yp_album02)의 관계를 확인한다.
- 요청 사이에 지연을 두고, 이미 받은 파일은 건너뛰어 중간에 멈춰도 재개할 수 있게 한다.

[이미지 정리 (AI 보정용)]
- 모든 이미지를 images-original/ 에 "<구분>-<글번호>-<순번>.<확장자>" 이름으로 복사한다(예: project-068-01.jpg, company-license-01.jpg).
- images-original/list.csv: 파일명, 원래 글 제목, 구분(회사/시공), 가로×세로, 용량, 용도 추정(대표사진·본문·증명서 등).
- 증명서·등록증처럼 내용이 바뀌면 안 되는 이미지는 list.csv에 "보정 주의"로 표시한다.

작업 후 게시판별 글 수, 이미지 수와 총 용량, 실패 목록을 보고하고 멈춘다. 새 사이트 코드는 아직 만들지 않는다.
```

## 1단계 프롬프트: 메뉴 구조와 디자인 시안

```
shion.co.kr 리뉴얼 1단계: 메뉴 구조와 디자인 시안을 만들어줘. backup/ 의 실제 글과 사진(있으면 images-final/의 다듬은 사진)을 쓴다.

[목표]
- 기존 내용은 그대로 살리고, 오래된 사이트를 세련된 최신 느낌으로 바꾸는 것. 기능은 늘리지 않지만 디자인·모션은 공들인다.
- 회사: 스카이드릴 천공, 와이어메쉬 설치, 대형 숏크리트 타설 등 사면·지반 보강 전문 시공사.
- 방문자: 건설사·공공 발주처 담당자, 협력업체. 휴대폰으로 많이 본다. 목적은 "믿을 만한 업체인지 보고 바로 전화하기".
- 인상: 신뢰감, 기술 전문성, 세련됨. 큰 사진, 과감한 타이포그래피, 공들인 모션으로 "요즘 회사"처럼 보이게 한다.

[1차: 메뉴 구조 (여기서 멈춤)]
- 출발점 제안: 회사소개 / 사업분야 / 시공실적 / 문의하기 (4개 이하). 기존 7개 기업소개 항목은 회사소개 한 페이지의 구역으로 합치는 안을 기본으로 한다.
- 페이지 목록과 각 페이지 내용, 새 주소 규칙을 표로 보여주고 확인을 받는다.

[2차: 시안 3안 (여기서 멈춤)]
- mockups/ 에 정적 HTML 3안. 각 안: 메인 첫 화면 + 사업분야 영역 + 시공실적 카드 + 모바일 하단 전화 버튼.
- 안마다 색·글꼴·레이아웃·모션 성격을 한 줄로 설명한다.
- Playwright로 데스크톱(1440px)·모바일(390px) 스크린샷을 찍어 확인하고 고친 뒤 보고한다.
- 내 선택을 기다린다.

[공통 기준]
- 디자인·애니메이션은 심플하게 줄이지 않는다. 첫 화면 모션, 스크롤에 따른 등장·전환, 사진 패럴랙스, 호버 효과 등 요즘 사이트 수준으로 만들되, 안마다 모션 강도를 다르게 해서 비교할 수 있게 한다.
- 모션 라이브러리(GSAP, Lenis 등)는 필요하면 써도 된다. 다만 정보를 가리지 않게 하고 prefers-reduced-motion을 지원한다.
- 한글 웹폰트는 필요한 굵기만. 글자 대비와 키보드 이동 등 기본 접근성.
```

## 2단계 프롬프트: 사이트 제작

```
shion.co.kr 리뉴얼 2단계: 1단계에서 선택한 시안과 메뉴 구조로 실제 사이트를 만들어줘.

[기술]
- Eleventy(11ty) 정적 사이트. 설치 전 공식 문서에서 현재 패키지 이름·안정 버전을 확인한다(이름 변경 언급이 있었음).
- npm run dev(미리보기), npm run build(정적 파일). 특정 호스팅에 의존하지 않는다.
- 빌드 과정은 단순하게: Eleventy 하나로 끝나게 하고, 별도 번들러나 직접 만든 빌드 스크립트는 넣지 않는다. 모션 라이브러리는 1단계에서 고른 것을 그대로 쓴다.

- 프로젝트 루트에 CLAUDE.md를 만들어 목표, 결정 사항, 폴더 구조, 검증 방법을 적는다.

[설정: src/_data/site.json]
- 회사명, 주소, 전화번호(대표 02.960.0890 / 휴대폰 010.7773.0895 / 02.3295.0891은 전화·팩스 미확정이라 표기를 쉽게 바꿀 수 있게), 이메일 sion5964@naver.com, 주소 서울시 성북구 한천로 66길189 (석관동 135-2, 브룩스톤 오피스텔 307호), naverVerification b068707badafeb96f10f3f5204b433a1b901e669. 헤더·푸터·문의하기는 모두 여기서 읽는다.

[페이지]

- 시공실적: src/content/projects/<YYYY-MM-DD>-<슬러그>/index.md 하나에 사진 여러 장과 동영상(유튜브)을 담는다. 기존 시공사진·동영상·사례 글을 모두 여기로 변환하고, 작성일은 date로 정확히 옮긴다. 목록은 최신순 카드 + 페이지네이션, 상세는 사진 갤러리.

- 문의하기: 게시판 없이 정적 페이지. 전화 tel: 링크, 이메일 텍스트 + 복사 버튼, 주소와 네이버지도 링크. 안내 문구: "홈페이지를 관리하는 별도 담당자가 없어 문의는 전화 또는 이메일로 받고 있습니다. 전화로 문의하시거나, 공내역서와 회신받으실 연락처를 이메일로 보내주시면 더욱 상세히 견적해서 보내드리겠습니다." 모바일에서는 모든 페이지 하단에 전화 버튼.

[기본 SEO]

[확인]

작업 후 바뀐 파일과 로컬 실행 방법을 보고한다.
```

## 3단계: 이미지 교체 (프롬프트 불필요)

- 다른 AI로 다듬은 이미지를 `images-original/`과 **같은 파일명**으로 `images-final/`에 넣고 `npm run build`만 하면 반영됩니다.
- 증명서·등록증은 내용이 바뀌지 않았는지 눈으로 확인합니다.
- 실제 현장 사진을 AI로 다듬을 때는 시공 내용이 과장되거나 바뀌지 않게 합니다(발주처가 실제 현장으로 보기 때문입니다).

## 4단계 메모: 배포 (호스팅 확정 후 프롬프트 작성)

- 호스팅 연결과 자동 배포, 도메인·HTTPS.
- redirects.json 적용과 옛 주소 몇 개로 동작 확인.
- 네이버 서치어드바이저에 사이트맵 제출, 인증 메타태그 유지 확인.
