## 알게 된 것

- **회사소개 페이지들은 페이지 빌더로 만들어져** 있어 원본 HTML에 편집 도구 글자가 섞여 있습니다. 스크립트가 걸러낸 본문은 각 글 폴더의 `content.txt`에 있습니다. PC용과 모바일용 문단이 두 번씩 들어 있으니 옮길 때 한 번만 씁니다.
- **주요사업(공법) 5가지**: 스카이드릴 천공작업, WIREMESH 설치, ROCKBOLT 체결·배수공 설치, 대형 숏크리트머신 타설, SHOT CRETE 타설 완료.
- **취급공종**(시공사례 페이지): 토공사, 사면보강(가시설, shot crete, rock bolt, soil nailing, 녹생토·코아네트).
- 시공 글은 "1. 장비 셋팅 → 2. T.B.M(안전조회) → 3. 숏크리트 타설"처럼 **공정 순서대로 사진과 소제목**이 붙어 있습니다. 새 사이트의 시공실적 상세를 "공정 단계" 형태로 보여주기 좋습니다.
